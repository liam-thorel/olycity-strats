    Ajouter depuis TikTok

    💬 Par Discord iPhone et Android

    Dans TikTok : Partager → Discord → salon strats-r6 du serveur OLYCITY. Le bot ajoute la strat (titre, map, agents, copie de la vidéo) et répond avec le lien vers la fiche. Plusieurs liens dans un même message marchent aussi.

    🤖 Android appli installée

    1. Installe le site : dans Chrome, menu ⋮ → Ajouter à l'écran d'accueil (ou « Installer l'application »).
    2. Dans TikTok : Partager → Plus (ou « Autres ») → Strats R6. La fiche s'ouvre préremplie.

    🍎 iPhone

    TikTok ne transmet pas le lien aux raccourcis iPhone : utilise Discord (ci-dessus) ou Copier le lien + 📋 Coller (ci-dessous).

    Raccourci « tap au dos » (facultatif)
    1. App Raccourcis → + → action URL : Encoder avec la variable Presse-papiers.
    2. Action Ouvrir les URL : https://strats.olycity.fr/?add= puis la variable URL encodée.
    3. Réglages → Accessibilité → Toucher → Toucher le dos → Toucher deux fois → ce raccourci.
    4. Dans TikTok : Copier le lien, puis deux petits coups au dos du téléphone.

    📋 Le plus simple tous les téléphones

    Dans TikTok : Partager → Copier le lien, puis sur ce site : bouton 📋 Coller. La fiche s'ouvre préremplie.
